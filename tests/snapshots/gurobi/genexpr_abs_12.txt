CVXPY
Minimize
  Sum(abs(X) + abs(Y), None, False)
Subject To
Bounds
 0.0 <= X
 0.0 <= Y
End
----------------------------------------
AFTER COMPILATION
Minimize
  x_0 + x_1 + x_2 + x_3
Subject To
 R0: - x_0 + x_4 <= 0
 R1: - x_1 + x_5 <= 0
 R2: - x_0 - x_4 <= 0
 R3: - x_1 - x_5 <= 0
 R4: - x_2 + x_6 <= 0
 R5: - x_3 + x_7 <= 0
 R6: - x_2 - x_6 <= 0
 R7: - x_3 - x_7 <= 0
Bounds
 x_0 free
 x_1 free
 x_2 free
 x_3 free
End
----------------------------------------
GUROBI
Minimize
  0 X[0] + 0 X[1] + abs_1 + abs_2 + 0 Y[0] + 0 Y[1] + abs_3 + abs_4
Subject To
Bounds
General Constraints
 GC0: abs_1 = ABS ( X[0] )
 GC1: abs_2 = ABS ( X[1] )
 GC2: abs_3 = ABS ( Y[0] )
 GC3: abs_4 = ABS ( Y[1] )
End
